# Foto delle specie

Per aggiungere una foto al catalogo, salva in questa cartella un'immagine in
formato AVIF con lo stesso nome del file della scheda, sostituendo `.html` con
`.avif`. Per esempio, per la scheda `cavedano-italiano.html` usa
`cavedano-italiano.avif`. Il nome previsto per ogni specie si trova nel
collegamento "Apri la scheda" in `specie.html`.

La foto appare automaticamente nel catalogo; se il file manca o non viene
caricato rimane la scritta "Foto in arrivo". Per pubblicarla online, aggiungi
anche il file al sito e aggiorna la pubblicazione.

Usa solo immagini per cui hai il permesso di pubblicazione e aggiungi eventuali
crediti e informazioni sulla licenza richiesti dall'autore.
